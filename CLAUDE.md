# CLAUDE.md — WG·ARCADE

Karim antwortet auf Deutsch, programmiert nicht selbst, mag es lean; keine Erklärungen ungefragt.

- Node/npm: `export PATH="$HOME/.local/share/herdr-web-ui/node/bin:$PATH"` (nicht im Standard-PATH).
- Befehle: `npm run dev` · `npm test` · `npm run lint` · `npm run build`.
- Bau-Regeln und Konventionen: `.claude/hew.md`.
