## Findings
- [MINOR] planOrder never stops when ids is empty — src/engine/rounds.ts: if `ids` is empty, `shuffle(rng, [])` returns []. `out` never grows and `while (out.length < n)` never ends. createEngine passes `ids = GAME_IDS.filter(id => id in games)`, so a registry with no matching GameId key (a partial registry in step 4, or a misconfigured `only` filter) makes `control({a:'start'})` hang the host tab without any error. A cheap guard would fix it: `must`/throw in createEngine when `ids.length === 0`, or in planOrder.
- [NOTE] Step 5: D-5 lobby removal conflicts with reconnect when the old conn closes — In the lobby, `disconnect(pid)` removes the player completely (D-5). Master plan §3.7 says: when a pid binds to a new conn, the old conn is closed. If host.ts sends the old conn's onClose to `engine.disconnect(pid)`, a player who reconnects in the lobby is removed right after rejoining. host.ts must only call disconnect when the closing conn is still the one bound to that pid. Worth a dedicated test in step 5.
- [NOTE] Test-correction commit ae39ac5 has no vitest summary in its body — ae39ac5 changes the play-view JSON-stability test from t+100 to t+50, because 100 ms is the dummy deadline at speed 10, and adds `expect(later.phase.k).toBe('play')`. This is a legitimate pre-impl correction and makes the test stricter, not weaker. The step plan's commit rule says commit bodies carry the vitest summary. This commit has no body. Cosmetic.
- [NOTE] Name length counts UTF-16 code units — party.ts hello checks `name.trim().length` against 1..12. Emoji and other astral characters count 2 each, so a name of 7 emoji is rejected as badname. The spec does not cover this. When the step-5/6 input field sets maxlength, keep the two consistent or count code points instead.
- [NOTE] The intro accent assertion cannot tell games apart — makeDummy always uses accent 'lime', so the intro view test cannot detect a bug where the accent does not come from the current round's def. It does not matter now (title/rule are per-id and do cover defAt). The real games in step 4 will have distinct accents.
